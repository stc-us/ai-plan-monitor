How monitoring works

  • Daily check: official pricing pages first, then trackers. A change is reported only when the checked value differs from the baseline in data/prices.json.
  • Three states: changed = report + update baseline after the report is confirmed sent; unchanged = silent, no write; unknown = check failed / no data — recorded as “not verified”, never stamped unchanged.
  • Watermark: apply a result only if its check time is newer than that provider's watermark, so a late older result never rolls the baseline back.
  • Verify before claiming live: never report a deal from a coupon site alone — verify on the provider's own page or a dated official announcement.
